# Checklist de Entrega

STATUS: ACTIVE
OWNER: Coordenação do Odonto.IA
LAST_REVIEWED: 2026-10-11
REPLACES: nenhum
CANONICAL_FOR: critério de entrega

## Produto

- [ ] objetivo atendido
- [ ] usuário correto
- [ ] fluxo aprovado
- [ ] permissões explícitas
- [ ] estados de erro considerados
- [ ] fora de escopo respeitado

## Código

- [ ] implementação mínima necessária
- [ ] nenhuma abstração gratuita
- [ ] nenhum arquivo estranho ao escopo alterado sem justificativa
- [ ] contratos atualizados
- [ ] migrações revisadas, se houver

## Testes

- [ ] critérios de aceite validados
- [ ] testes relacionados passando
- [ ] regressão relevante executada
- [ ] fluxos compartilhados revisados

## Auditoria

- [ ] achados confirmados tratados
- [ ] falsos positivos separados
- [ ] nenhum loop de correção ativo

## Design

- [ ] usa padrões atuais
- [ ] não reutiliza artefato superado
- [ ] consistência com telas relacionadas
- [ ] densidade visual aceitável
- [ ] solução simplificada quando possível

## Documentação

- [ ] fonte de verdade atualizada
- [ ] documento antigo marcado como substituído, se necessário
- [ ] handoff criado
- [ ] próxima ação registrada

## Entrega

A tarefa pode ser marcada como `DONE` apenas se os itens críticos acima forem satisfeitos.
